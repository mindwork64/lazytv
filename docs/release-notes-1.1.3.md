# LazyTV 1.1.3

**Сессия больше не слетает: код сопряжения вводится один раз.**

---

## Что нового

### 🔑 Сессия восстанавливается автоматически

Раньше приложение хранило только сессию и переиспользовало её при следующем
запуске. Телевизор считал такую сессию устаревшей и отвечал `401`, поэтому
код сопряжения приходилось вводить каждый раз.

Теперь приложение хранит **ключ сопряжения** (6-значный код) и на каждом
запуске заново получает по нему свежую сессию (`AuthReq`) — это и есть
штатный механизм NetCast. Пульта достаточно, чтобы телевизор был включён;
PIN нужен только при первом подключении.

Если телевизор действительно забыл сопряжение (сброс, другое устройство),
приложение сообщит об этом и попросит новый код. Если телевизор просто
выключен или недоступен, ключ сохраняется — следующий запуск повторит
попытку, и повторное сопряжение не потребуется.

### 🔄 Тихая переаутентификация при `401`

При истечении сессии во время работы приложение сначала молча
переаутентифицируется по ключу и только при отказе возвращается к экрану
сопряжения — без потери сохранённого адреса и ключа.

### ⚙️ Хранилище

В `~/.config/lazytv/config.json` добавлено поле `pairingKey`. Пункт
**Настройки → Отключиться и забыть сессию** очищает и адрес, и ключ, и
сессию.

### 📦 Установка

**Ubuntu 24.04 (noble):**

```bash
sudo apt update
sudo apt install lazytv
```

**Другие дистрибутивы:** скачайте `lazytv-1.1.3-x86_64.AppImage`
со страницы релиза.

## Что осталось как было

- Весь функционал пульта: сопряжение, D-Pad, громкость (`VOL`), канал
  (`CH`), Home/Exit, цифровая клавиатура.
- Горячие клавиши на экране пульта и переключатель «Горячие клавиши»
  в настройках — как в 1.1.2.
- Настройки: адрес телевизора, «Отключиться и забыть сессию», тема
  (системная / тёмная / светлая), вывод версии.
- Соединение с ТВ: чтение ответа по `Content-Length`, обработка `401`,
  разбор `ROAPError`, 60-секундный таймаут на повторный запрос кода.
- Публичный API библиотеки: `lazytv::Client` — без изменений, совместим
  с 1.1.2.
- Три способа установки: PPA, AppImage, из исходников.
