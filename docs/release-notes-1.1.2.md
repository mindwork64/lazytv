# LazyTV 1.1.2

**Управление телевизором с клавиатуры и обновлённая иконка приложения.**

---

## Что нового

### ⌨️ Горячие клавиши

Когда открыт экран пульта, клавиатура работает как кнопки телевизора:

- стрелки — навигация, `Enter`/`Space` — OK, `Esc` — BACK,
  `Backspace` — EXIT;
- `P` — Power, `M` — Mute, `H` — HOME, `I` — INFO;
- `+`/`=` и `−` — громкость, `Page Up`/`Page Down` — канал;
- `0`–`9` — цифры (основной ряд и цифровой блок), `Tab` — переключение
  основной и цифровой панели.

Нажатие подсвечивает соответствующую кнопку на экране (120 мс). При
удержании стрелок, громкости и каналов команда повторяется — не чаще
5 раз в секунду, поэтому очередь команд клиента не растёт и ТВ
останавливается сразу после отпускания. Для Power, Mute, HOME, EXIT,
INFO и цифр автоповтор отключён.

Сочетания с Ctrl/Alt/Meta не перехватываются — они остаются системе.
В сопряжении и настройках клавиши работают как обычно: `Tab`/`Enter`
ходят по элементам формы.

### ⚙️ Настройка «Горячие клавиши»

Перехват можно отключить — новый пункт в настройках. Значение хранится
в `~/.config/lazytv/config.json` (`hotkeysEnabled`), по умолчанию
включено.

### 🎨 Иконка приложения

Иконка перерисована: проще форма, лучше читается в маленьких размерах
(меню приложений, док).

### 📦 Установка

**Ubuntu 24.04 (noble):**

```bash
sudo apt update
sudo apt install lazytv
```

**Другие дистрибутивы:** скачайте `lazytv-1.1.2-x86_64.AppImage`
со страницы релиза.

## Что осталось как было

- Весь функционал пульта: сопряжение, D-Pad, громкость (`VOL`), канал
  (`CH`), Home/Exit, цифровая клавиатура.
- Настройки: адрес телевизора, «Отключиться и забыть сессию», тема
  (системная / тёмная / светлая), вывод версии.
- Индикатор состояния связи в статус-баре и баннеры ошибок команды.
- Соединение с ТВ: чтение ответа по `Content-Length`, обработка `401`
  (`sessionExpired`), разбор `ROAPError`, 60-секундный таймаут на
  повторный запрос кода сопряжения — как в 1.1.1.
- Публичный API библиотеки: `lazytv::Client` — без изменений,
  совместим с 1.1.1.
- Три способа установки: PPA, AppImage, из исходников.
