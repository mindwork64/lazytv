# LazyTV 1.1.1

**Исправления сопряжения и устойчивости соединения с телевизором.**

---

## Что нового

### 🔌 Соединение с телевизором

- Тело HTTP-ответа читается по `Content-Length` вместо ожидания разрыва
  соединения — команды и сопряжение перестали «теряться» на медленном
  отклике ТВ.
- При HTTP 401 от ТВ клиент поднимает `sessionExpired`, очищает сессию,
  а приложение возвращает на экран сопряжения с пояснением.
- В ответе ROAP разбираются `ROAPError`/`ROAPErrorDetail` — при отказе
  видно причину, а не молчаливое «команда не прошла».
- Кнопка запроса кода сопряжения блокируется на 60 секунд после
  успешного запроса: повторный запрос аннулирует код, показанный на ТВ.
- Версия приложения (`--version` и раздел «Версия» в настройках) берётся
  из сборки — из `CMakeLists.txt`, без зашитых строк.

### 🏷 Идентификаторы

- Пакет, приложение в меню, команда и namespace — `lazytv` / `LazyTV`,
  без использования торговой марки LG.
- CMake-цели: `LazyTV::Core`, `LazyTV::Client`; заголовки
  `#include <lazytv/...>`; конфиг `~/.config/lazytv/`.

### 📦 Установка

**Ubuntu 24.04 (noble):**

```bash
sudo apt update
sudo apt install lazytv
```

**Другие дистрибутивы:** скачайте `lazytv-1.1.1-x86_64.AppImage`
со страницы релиза.

### ⚠️ Важно при обновлении

Если ранее использовался пакет `lgremote`, его нужно удалить и
перенести конфиг:

```bash
sudo apt remove lgremote
mv ~/.config/lgremote ~/.config/lazytv   # если файл ещё не перенесён
```

## Что осталось как было

- Весь функционал пульта: сопряжение, D-Pad, громкость (`VOL`), канал
  (`CH`), Home/Exit, цифровая клавиатура.
- Настройки: адрес телевизора, «Отключиться и забыть сессию», тема
  (системная / тёмная / светлая), вывод версии.
- Индикатор состояния связи в статус-баре и баннеры ошибок команды —
  как в 1.1.0.
- Публичный API библиотеки: `lazytv::Client` — без изменений,
  совместим с 1.1.0.
- Три способа установки: PPA, AppImage, из исходников.
