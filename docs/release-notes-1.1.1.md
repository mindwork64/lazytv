# LazyTV 1.1.1

**Исправления сопряжения и устойчивости соединения с телевизором.**

---

## Что нового

### 🔌 Соединение с телевизором

- Прогрев TCP-соединения при старте приложения и автоматический повтор
  первой команды — пульт отзывается с первого нажатия.
- Периодическая проверка доступности телевизора (TCP-probe) на экране
  пульта: видно, отвечает ли ТВ, ещё до отправки команды.
- Тело HTTP-ответа читается по `Content-Length`, а не «до конца потока» —
  корректно обрабатываются ответы сервера NetCast.
- Обработка истечения сессии: если ТВ отверг сессию, приложение
  предлагает повторить сопряжение вместо тихого отказа команд.

### 🏷 Идентификаторы

- Пакет, приложение в меню, команда и namespace — `lazytv` / `LazyTV`,
  без использования торговой марки LG.
- CMake-цели: `LazyTV::Core`, `LazyTV::Client`; заголовки
  `#include <lazytv/...>`; конфиг `~/.config/lazytv/`.
- Флаг `--version` печатает версию, взятую из `CMakeLists.txt`.

### 📦 Установка

**Ubuntu 24.04 (noble):**

```bash
sudo apt update
sudo apt install lazytv
```

**Другие дистрибутивы:** скачайте `lazytv-1.1.1-x86_64.AppImage`
со страницы релиза.

### ⚠️ Важно при обновлении

Если ранее использовался пакет `lgremote`, его нужно удалить и
перенести конфиг:

```bash
sudo apt remove lgremote
mv ~/.config/lgremote ~/.config/lazytv   # если файл ещё не перенесён
```

## Что осталось как было

- Весь функционал пульта: сопряжение, D-Pad, рокеры, цифровая
  клавиатура, настройки (энергосбережение, соотношение сторон,
  громкость).
- Публичный API библиотеки: `lazytv::Client` — без изменений,
  совместим с 1.1.0.
- Три способа установки: PPA, AppImage, из исходников.
