# LazyTV 1.2.0

**Что показывает телевизор — теперь видно прямо на пульте.**

---

## Что нового

### 📺 Строка «сейчас в эфире»

Над кнопками пульта появилась строка с текущим состоянием телевизора:

- номер и название канала;
- название передачи, которая идёт сейчас;
- громкость и признак `MUTE`.

Длинные названия аккуратно сокращаются, полный текст доступен во всплывающей
подсказке. Данные обновляются каждые 5 секунд, пока открыт пульт, и сразу
после переключения канала или изменения громкости.

### 📡 Новые запросы к телевизору

В протокол добавлены запросы данных NetCast:

- `cur_channel` — текущий канал и программа;
- `channel_list` — список каналов;
- `volume_info` — уровень громкости и `MUTE`;
- `screen_image` — кадр экрана телевизора в JPEG (960×540).

Сначала используется endpoint `/roap/api/data`; если телевизор отвечает
`404`, приложение автоматически переключается на `/udap/api/data`. Так
поддерживаются разные поколения NetCast в пределах 2010–2014.

### 📚 Страница «Каналы»

Через меню «…» в верхней строке открывается список каналов телевизора.
Клик по каналу переключает на него напрямую (команда `HandleChannelChange`)
и возвращает на пульт.

### 🖼 Страница «Экран ТВ»

Там же можно запросить кадр экрана телевизора. Изображение загружается
по кнопке «Обновить», без постоянного опроса — чтобы не нагружать ТВ.

### 🔄 Экономный опрос

Фоновые запросы идут только пока пульт виден. После команд канала,
громкости, цифр или переключения входа выполняется внеочередное
обновление, поэтому строка «сейчас в эфире» не ждёт следующего цикла.

### 📦 Установка

**Ubuntu 24.04 (noble):**

```bash
sudo apt update
sudo apt install lazytv
```

**Другие дистрибутивы:** скачайте `lazytv-1.2.0-x86_64.AppImage`
со страницы релиза.

## Что осталось как было

- Сопряжение по 6-значному коду и тихое восстановление сессии по ключу.
- Весь функционал пульта: D-Pad, громкость (`VOL`), канал (`CH`),
  Home/Exit, цифровая клавиатура, горячие клавиши.
- Настройки: адрес телевизора, «Отключиться и забыть сессию», тема
  (системная / тёмная / светлая), вывод версии.
- Индикатор состояния связи и баннеры ошибок команды.
- Три способа установки: PPA, AppImage, из исходников.

Публичный API `lazytv::Client` расширен новыми запросами и сигналами;
существующие методы и поведение не менялись.
