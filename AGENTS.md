# AGENTS.md — правила для AI-агентов

Короткая шпаргалка для любых агентов, работающих с репозиторием LazyTV.
Дополняет [apidocs/PROJECT.md](apidocs/PROJECT.md) и
[apidocs/ADR.md](apidocs/ADR.md).

## Формат работы

- **DeepSeek в веб-чате** — по-прежнему выдавать файлы **целиком**
  ([ADR-019](apidocs/ADR.md#L273-L284)).
- **Работа из harness** (CLI/IDE-агент) — только **локальные точечные
  правки**; целые файлы не выводить и не переписывать без необходимости.
- **Большие файлы читать фрагментами** — `grep`, `sed -n`, offset/limit, —
  а не целиком.
- **Минимум итераций:** сразу предлагать финальный вариант с кратким
  пояснением, без пробных прогонов. Экономить выходные токены.

## Что нельзя нарушать

- C++20, Qt 6.4+ (`Core`, `Gui`, `Widgets`, `Network`, `Svg`), CMake 3.21+.
- Цели: `lazytv-core`, `lazytv`, `lazytv-app`; публичный API — `namespace
  lazytv`, заголовки в `include/lazytv/`.
- Не менять имена классов/targets без явного запроса; не переписывать
  архитектуру ради локальной задачи; новые зависимости — только по
  согласованию.
- Стиль: 4 пробела, `m_` для полей, `kCamelCase` для констант, `#pragma once`,
  комментарии и UI-строки по-русски.
- Проверка: сборка + `QT_QPA_PLATFORM=offscreen ./build/lazytv --version`;
  автотестов нет.
- Коммиты: Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`), релиз —
  `Release X.Y.Z`; версия синхронно в `CMakeLists.txt`, `debian/changelog`,
  release notes и теге.

## Подводные камни

- `.gitignore` содержит `apidocs/`: новые файлы там не попадут в `git add -A`
  без `git add -f`.
- В коде смешаны 2 и 4 пробела: в существующих 2-space файлах сохранять
  локальный стиль, в новых — 4 пробела.
